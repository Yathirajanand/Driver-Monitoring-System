# Driver Monitoring System

## Overview

The Driver Monitoring System is a computer vision-based project focused on monitoring driver behaviour and supporting road safety through automated analysis.

The project explores the use of image processing and machine learning techniques to analyse driver-related visual information and identify potentially unsafe driving conditions.

## Objectives

- Develop a software-based driver monitoring solution.
- Explore computer vision techniques for analysing driver behaviour.
- Identify potential indicators of unsafe driving conditions.
- Provide a foundation for automated driver safety monitoring.
